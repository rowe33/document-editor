# A4 Document Editor (Редактор документов A4)

**A4 Document Editor** — это легкий, полностью клиентский веб-редактор документов формата A4, выполненный в современном стиле macOS/iOS (Glassmorphism). Приложение работает прямо в браузере без необходимости настройки сервера или установки сторонних зависимостей.

## 🚀 Особенности и возможности

- **Форматирование A4 в реальном времени**:
  - Точные размеры страниц A4 ($794 \times 1123$ px).
  - Автоматический перенос текста (reflow) между страницами при заполнении.
  - Поддержка разрывов страниц (`Ctrl + Enter`).
  - Настройка полей страницы (верхнее, нижнее, левое, правое в мм) с готовыми пресетами (Обычные, Узкие, Широкие).

- **Богатые возможности форматирования**:
  - Выбор шрифтов (Arial, Times New Roman, Georgia, Montserrat, Roboto, PT Serif и др.).
  - Точная настройка размера шрифта и межстрочных интервалов.
  - Базовое стилизование: жирный, курсив, подчёркнутый, зачёркнутый текст.
  - Настройка цвета текста и цвета выделения (маркер).
  - Выравнивание текста (по левому краю, по центру, по правому краю, по ширине).
  - Нумерованные и маркированные списки, управление отступами абзацев (`Tab` / `Shift+Tab`).
  - Вставка горизонтальных разделительных линий разного стиля (тонкая, двойная, пунктирная и т.д.).

- **Работа с изображениями**:
  - Загрузка изображений с компьютера или по URL-ссылке.
  - Интерактивное изменение размера за угол изображения.
  - Быстрое масштабирование (25%, 50%, 100%) и выравнивание внутри текста.

- **Управление документами и автосохранение**:
  - Встроенный менеджер документов с сайдбаром и поиском.
  - Автоматическое сохранение изменений в `localStorage` браузера.
  - Создание, переименование и удаление документов.

- **Экспорт**:
  - Экспорт выбранных или всех страниц документа в файлы формата **JPG** с высоким разрешением (благодаря `html2canvas`).

- **Интерфейс**:
  - Адаптивный Glassmorphism-дизайн.
  - Поддержка **светлой** и **тёмной** тем оформления с сохранением предпочтений.

## 🛠 Технологический стек

Проект реализован без использования фреймворков (Vanilla JS) и собран в одном HTML-файле:

- **HTML5 & CSS3**: Использование CSS Custom Properties, Flexbox, Grid, Backdrop Filter, CSS-переменных для динамических тем.
- **JavaScript (ES6+)**: Чистый JS для обработки range-выделений, автоматического пересчета переносов страниц и управления манипуляциями с DOM.
- **Внешние библиотеки (CDN)**:
  - [Google Fonts](https://fonts.google.com/) — подключение качественных веб-шрифтов (Montserrat, PT Serif, Roboto).
  - [html2canvas v1.4.1](https://html2canvas.hertzen.com/) — генерация изображений высокой четкости при экспорте страниц.

## 📦 Быстрый старт

Так как весь проект упакован в одиночный файл `index.html`, запустить его очень просто:

1. Скачайте файл `index.html` или клонируйте репозиторий.
2. Откройте `index.html` в любом современном веб-браузере (Chrome, Firefox, Edge, Safari).

*Никаких команд `npm install`, серверов сборки или настройки окружения не требуется.*

## ⌨️ Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Ctrl + Z` | Отменить последнее действие |
| `Ctrl + Y` | Повторить отмененное действие |
| `Ctrl + B` | Жирный текст |
| `Ctrl + I` | Курсив |
| `Ctrl + U` | Подчёркнутый текст |
| `Ctrl + Enter` | Вставить разрыв страницы |
| `Tab` | Увеличить отступ абзаца |
| `Shift + Tab` | Уменьшить отступ абзаца |
| `Escape` | Закрыть модальное окно |

---

## 💾 Хранение данных

Все созданные документы, их содержимое и пользовательские настройки страницы сохраняются локально в вашем браузере с помощью `localStorage` (ключи с префиксом `a4d:`). Данные не передаются на сторонние сервера.
